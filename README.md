# Sparta Cursos — Landing Page

Projeto de **site institucional/landing page responsiva** desenvolvido para apresentação em portfólio.

> **Importante:** este repositório é um projeto demonstrativo. Os depoimentos, login e formulário são exemplos de interface. O número de WhatsApp no JavaScript é um **placeholder** e deve ser substituído pelo contato oficial antes de qualquer publicação comercial.

## ✨ Visão geral

A proposta do projeto é apresentar uma experiência moderna para uma plataforma de cursos preparatórios, com foco em:

- apresentação clara dos cursos;
- preços e modalidades;
- navegação responsiva;
- chamadas para ação;
- contato rápido via WhatsApp;
- experiência otimizada para celular;
- estrutura pronta para publicação no GitHub Pages.

## 🧩 Tecnologias

- HTML5

- Git e GitHub
- GitHub Pages

## 🚀 Como executar

### Opção 1 — navegador

Baixe/clique no projeto e abra:

```text
index.html
```

### Opção 2 — VS Code

Abra a pasta no VS Code e execute com uma extensão como **Live Server**.

## 🌐 Publicar no GitHub Pages

1. Crie um repositório chamado `sparta-cursos`.
2. Envie os arquivos deste projeto.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Salve.
6. Aguarde a publicação do GitHub Pages.

O endereço normalmente ficará parecido com:

```text
https://SEU-USUARIO.github.io/sparta-cursos/
```

## 🔧 Antes de publicar comercialmente

No arquivo `script.js`, altere:

```js
const numero = "5582999999999";
```

para o WhatsApp oficial da empresa.

Também é recomendado:

- substituir os depoimentos demonstrativos por depoimentos autorizados;
- inserir logo e imagens oficiais;
- conectar o formulário a um backend ou serviço de formulários;
- implementar autenticação real se a área do aluno for necessária;
- revisar preços, datas e horários antes da publicação.
